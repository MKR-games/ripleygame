RIPLEY — 리플리 게임 v2
=======================

실행 방법
1. ZIP 압축을 풉니다.
2. index.html을 Chrome / Edge / Safari 등 최신 브라우저에서 엽니다.
3. 우측 상단 ⛶ 버튼을 누르면 브라우저가 지원하는 경우 전체 화면으로 전환됩니다.

게임 01: 리플리 – 시민을 속여라
- 한 대의 스마트폰으로 플레이
- 플레이어 이름 입력 없음: 첫 번째 / 두 번째 / 세 번째... 순서로만 구분
- 총 인원 3~12명 설정 가능
- 리플리 수 / 시민 수 직접 설정 가능
- 리플리는 다수, 시민은 소수로 설정
- 리플리 전원은 같은 단어, 시민 전원은 비슷하지만 다른 같은 단어를 받음
- 누구에게도 역할명(리플리/시민)을 미리 공개하지 않음
- 총 100개 단어 조합
- 같은 기기에서는 100개 조합을 가능한 한 중복 없이 순환
- 각 판마다 두 단어 중 어느 단어가 리플리 단어인지 무작위
- 역할 배치 무작위

진행 순서
1. 인원 / 리플리 / 시민 수 설정
2. 첫 번째 플레이어부터 비밀 단어 순차 확인
3. 전원이 한 번씩 발언 (발언 중 자수 없음)
4. 다시 한 명씩 휴대폰을 넘겨 개인 자수 확인: 예 / 아니요
5. 누군가 '예' 선택 시 자수 판정 후 결과 발표 대기 화면으로 이동
6. 전원이 '아니요' 선택 시 비밀 투표 시작
7. 모든 플레이어가 시민 의심자 한 명씩 비밀 선택
8. 실제 시민에게 간 표가 전체 투표의 과반수 이상이면 리플리 승리
9. 마지막 입력자는 정답을 먼저 볼 수 없으며, 휴대폰을 중앙에 놓고 결과 발표 버튼을 누름
10. 결과 화면에서 단어, 전원 역할, 투표 수 공개

게임 02: 리플리 – 인생 조작단
- 개발 예정 버튼으로 표시

파일 구성
- index.html
- styles.css
- app.js
- README.txt

별도 서버나 인터넷 연결이 필요하지 않습니다.


[v3 자수 규칙]
- 전원 발언 후 모든 플레이어가 비밀리에 자수 여부를 선택합니다.
- 여러 명이 자수할 수 있으며, 누가 '예'를 눌러도 전원 선택이 끝날 때까지 결과를 공개하지 않습니다.
- 한 명이라도 자수하면 비밀투표는 하지 않습니다.
- 자수한 시민은 생존합니다.
- 자수한 리플리는 해당 플레이어만 벌칙 대상이 됩니다.
- 자수하지 않은 시민도 벌칙 대상이 됩니다.
- 즉, 자수자가 있을 때 벌칙자 = 자수한 리플리 + 자수하지 않은 시민.
- 전원이 자수하지 않은 경우에만 비밀투표를 진행합니다.

[v5 모바일 UX/UI 및 결과 화면]
- 상단 전체화면 버튼을 콘텐츠와 겹치지 않는 고정 헤더의 우측으로 이동했습니다.
- 모바일 safe-area(노치/상단바/하단 홈 인디케이터)를 반영했습니다.
- 게임 진행 화면은 한 화면 한 행동 중심으로 정리하고 핵심 버튼을 손가락이 닿기 쉬운 아래쪽에 배치했습니다.
- 결과 발표 시 벌칙 대상 전용 경고 영역을 결과 상단에 크게 표시합니다.
- 벌칙 대상 이름, 벌칙 인원수, 벌칙 사유를 한눈에 볼 수 있습니다.
- 각 플레이어 판정에도 '🚨 벌칙' / '✓ 생존' 배지를 표시합니다.
