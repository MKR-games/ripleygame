실행: index.html
인터넷 연결 불필요 / 모바일 전체화면 지원

GAME 01 리플리 – 시민을 속여라
- 기존 단어/자수/비밀투표 구조 유지
- 발언 후 '정치 시간' 추가: 공개 지목, 변호, 거짓말 가능
- 자수는 끝까지 비밀
- 아무도 자수하지 않으면 기존 비밀투표
- 시민만 자수한 경우: 무승부가 아니라 시민 승리, 리플리 전원 벌칙
- 리플리만 자수한 경우: 자수한 리플리 + 자수하지 않은 시민 벌칙
- 시민/리플리가 함께 자수한 경우: 자수한 리플리 + 자수하지 않은 시민 벌칙
- 투표 동률은 시민 승리

GAME 02 리플리 – 인생 조작단
- 제시어 100개, 리플리 1명
- 시민: 자신의 경험은 진실, 의심/변호/정치 발언은 자유
- 리플리: 경험과 정치 모두 조작 가능
- 진술 후 정치 시간: 한 명씩 공개 지목, 실제 표는 비밀
- 단독 최다 득표자가 리플리면 시민 승리
- 그 외(시민 최다/공동 최다 포함)는 리플리 승리

두 모드 공통
- 결과 발표를 즉시 공개하지 않음
- 결과 발표 버튼 -> 단계 공개 -> 3·2·1 -> 최종 승패/벌칙
- Web Audio 기반 저음 두구두구 효과와 지원 기기의 진동 피드백 사용
