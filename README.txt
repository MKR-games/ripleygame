RIPLEY – 시민을 속여라 v5

실행 방법
1. ZIP 압축을 풉니다.
2. index.html을 실행합니다.
3. 모바일 브라우저에서 전체화면 버튼을 누르면 게임에 집중하기 좋습니다.

구성
- index.html
- styles.css
- app.js

주요 기능
- 3~12인 설정
- 리플리/시민 인원 직접 설정
- 100개 단어 조합
- 1폰 순차 단어 확인
- 전원 발언 후 비밀 자수
- 복수 자수 가능
- 자수자가 없을 때 비밀 투표
- 투표 동률은 시민 승리
- 벌칙 대상 강조 결과 화면
- 모바일 한 화면 중심 UI

자수 벌칙
자수한 리플리 + 자수하지 않은 시민
