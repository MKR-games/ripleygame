GAME 01 — 리플리: 시민을 속여라
- 기존 100개 유사 단어 조합 유지
- 역할은 공개하지 않고 각자 단어만 확인
- 전원 1회 설명 후 압박 질문 1회
- 압박 답변은 거짓말 가능, 단어 직접 공개 금지
- 자수는 전원 비밀 선택
- 아무도 자수하지 않으면 비밀투표
- 시민만 자수한 경우 즉시 승리하지 않음: 시민 진영이 리플리 단어를 맞혀야 최종 승리
- 투표에서 시민 진영이 잡힌 경우에도 시민에게 리플리 단어를 맞힐 마지막 역전 기회 제공
- 시민 추측 성공: 시민 역전 승리 / 리플리 벌칙
- 시민 추측 실패: 리플리 승리
- 동률은 시민 승리
